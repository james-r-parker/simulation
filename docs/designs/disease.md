# Disease

**Status:** Implemented - Phases 1 and 2 are built and the contagion is on by default at `diseaseSeedRate` 0.001 (user, 2026-11-03), a value taken from the T5 smoke run, not from a screen. Screening and confirming its values moved to [world-balance.md](world-balance.md) (T94 to T96). The browser frame-time check (T9) is owed: it needs the dev machine's GPU.
**Depends on:** [flora.md](flora.md), [megafauna.md](megafauna.md)

A contagion spreads by contact between blobs. Each strain is born on one host and copies a sample of that host's genome as its genotype. It infects a neighbour easily when the neighbour's genome is close to that genotype and hardly at all when it is far. A strain therefore runs through one family and stalls at strangers, and the most crowded, most uniform family is where outbreaks start and spread. Survivors are immune to that strain for life. Nothing in the rule knows which family is commonest: the cull comes from contact, density and relatedness, the way specialist pathogens hold back a dominant host in nature (negative frequency-dependent selection, the Janzen-Connell effect).

Scenes served ([principles.md](../principles.md)): **Boom and bust** (a crowded family swells and is cut back by an outbreak, and a neighbour family takes the ground), **Kin is not a stranger** (staying near kin now has a cost as well as a benefit), and the refusal **One niche allowed to win the whole map**. Selection rules 4 and 5 hold: the virus removes bodies, and the living recolonise; nothing is restocked.

## The contagion

`js/sim/disease.js` (new) owns the strain pool and three per-tick steps, run in order by `stepDisease(world)` in the `lifecycle` phase of `STEP_PHASES` (`js/sim/step.js`), directly after `stepToxin`.

| Step     | Rule                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Emerge   | When a strain slot is free and `world.population >= diseaseMinHosts`, a strain emerges with probability `diseaseSeedRate` this tick (one `nextFloat` draw from the `disease` stream). Its host is the healthy alive slot at index `nextInt(rng, healthy)` in slot order, `healthy` being the alive agents with no infection; with none, nothing emerges. The strain stores the host's `SIMILARITY_DIMS` sampled weights as its genotype (`sampleGenotype` in `genetics.js`) and infects the host |
| Transmit | Each infected agent, in slot order, visits every alive agent within `diseaseRadius` through `cellRange` on `world.hash`, in hash order. A neighbour that is not infected and not immune to the strain is infected with probability `diseaseTransmission x max(0, 1 - d / diseaseSpecificity)`, `d` being `distanceToGenotype(world, strain, slot)`. One `nextFloat` draw per pair whose chance is above 0. An agent infected this tick does not transmit until the next tick                     |
| Course   | An infected agent loses `diseaseDrain` energy per tick through `removeEnergy` with `LOSS_CAUSE.DISEASE` (new) for `diseaseTicks` ticks, then recovers: its infection clears and the strain's bit is set in its `immuneMask`                                                                                                                                                                                                                                                                      |

- A strain with no infected host is extinct: its slot frees, and its bit is cleared from every agent's `immuneMask`.
- `deathCause` in `js/sim/population.js` returns `DEATH_CAUSE.DISEASE` (new, 6) when the energy is 0, the agent is infected and `lastLoss` is `LOSS_CAUSE.DISEASE` or `LOSS_CAUSE.COST` (the drain or the tick's costs emptied it), checked after `TRAMPLED` and `EATEN`.
- A newborn and a floor entrant start healthy with an empty `immuneMask`. A freed slot clears both.
- Herds are not hosts.
- `diseaseSeedRate` 0 turns the contagion off: no draw is made from the `disease` stream, and the new arrays are left out of `hashWorld`, so every golden hash is unchanged.

### State

| Array (on the world)   | Type and size                            | Holds                                    |
| ---------------------- | ---------------------------------------- | ---------------------------------------- |
| `infection`            | `Uint8Array(maxAgents)`                  | 0 healthy, otherwise strain index plus 1 |
| `infectionTicks`       | `Int32Array(maxAgents)`                  | ticks left in the current infection      |
| `immuneMask`           | `Uint8Array(maxAgents)`                  | one bit per strain slot                  |
| `strainAlive`          | `Uint8Array(DISEASE_MAX_STRAINS)`        | 1 while the strain has a host            |
| `strainGenotype`       | `Float32Array(DISEASE_MAX_STRAINS x 64)` | the founding host's sampled weights      |
| `strainInfected`       | `Int32Array(DISEASE_MAX_STRAINS)`        | current host count                       |
| `strainTotal`          | `Int32Array(DISEASE_MAX_STRAINS)`        | hosts ever infected, for `StrainExtinct` |
| `strainFounderLineage` | `Int32Array(DISEASE_MAX_STRAINS)`        | the founding host's lineage id           |

`DISEASE_MAX_STRAINS` is 8, a constant in `disease.js` (the `immuneMask` width). `hashWorld` in `js/sim/world-hash.js` hashes these arrays only when `diseaseSeedRate > 0`. `assertInvariants` calls `assertDisease` (in `disease.js`): an `infection` value names an alive strain, `strainInfected` equals the count of agents carrying it, and no agent is both infected with and immune to one strain.

### Genetics helpers

`js/sim/genetics.js` gains two functions beside `geneticDistance`, sharing its `sampleOf` indices and scaling so the distances agree with the family detector in `js/evo/scene-families.js` (families are distance below 0.5):

- `sampleGenotype(world, slot, out, offset)` writes the slot's 64 sampled weights into `out` at `offset`.
- `distanceToGenotype(world, strain, slot)` returns the mean of `|w_slot - genotype| x invSd` over the 64 samples. It equals `geneticDistance` against the founding host while that host's weights are unchanged.

### Config

All keys are rules (they enter `rulesHash`), validated in `js/sim/config-rules.js` and defaulted in `js/sim/config-defaults.js`.

| Key                   | Type and range | Default | Meaning                                                    |
| --------------------- | -------------- | ------- | ---------------------------------------------------------- |
| `diseaseSeedRate`     | number, 0 to 1 | 0.001   | chance per tick that a strain emerges, when a slot is free |
| `diseaseMinHosts`     | int, >= 0      | 30      | the population below which no strain emerges               |
| `diseaseRadius`       | number, > 0    | 60      | contact distance, px, centre to centre                     |
| `diseaseTransmission` | number, 0 to 1 | 0.05    | chance per tick per contact at genetic distance 0          |
| `diseaseSpecificity`  | number, > 0    | 0.8     | genetic distance at which transmission reaches 0           |
| `diseaseDrain`        | number, >= 0   | 0.3     | energy lost per infected tick                              |
| `diseaseTicks`        | int, >= 1      | 600     | length of an infection                                     |

No key is a boolean or an enum, so `scripts/flag-ledger.json` gains no entry. `diseaseSeedRate` 0 turns the contagion off.

### Events

| Event (`EVENT_TYPE`) | Code | Fields after tick                                | Log (`js/sim/log.js`)   |
| -------------------- | ---- | ------------------------------------------------ | ----------------------- |
| `STRAIN_EMERGED`     | 26   | strain, host slot, host genomeId, host lineageId | `StrainEmerged` (info)  |
| `AGENT_INFECTED`     | 27   | slot, genomeId, strain, distance to genotype     | `AgentInfected` (debug) |
| `STRAIN_EXTINCT`     | 28   | strain, hosts ever infected, ticks alive         | `StrainExtinct` (info)  |

`AGENT_DIED` carries cause `DEATH_CAUSE.DISEASE`; `AgentDied` logs it by name. One infection per agent per tick keeps `MAX_EVENTS_PER_SLOT` (8) sufficient; the `eventCapacity` check in `js/sim/config-herds.js` adds `2 x DISEASE_MAX_STRAINS`.

## Detectors

`js/evo/scene-disease.js` (new), read by the observer from the events above, reported by `js/evo/metrics.js`. All are `watch` metrics, and all are `null` with reason `disease-off` while `diseaseSeedRate` is 0; `scripts/lib/watch-intent.mjs` lists `eval.disease_deaths_share` as lower, the others as higher.

| Metric                         | Scene or rule                          | Definition                                                                                                                                                                                                                                                                                                                                                                                           |
| ------------------------------ | -------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `eval.disease_deaths_share`    | Boom and bust                          | `AGENT_DIED` with cause `DISEASE` over all `AGENT_DIED` after burn-in (`BURN_IN_TICKS`). `null` with reason `no-deaths` when there are none                                                                                                                                                                                                                                                          |
| `eval.strains_per_100k`        | Boom and bust                          | `STRAIN_EMERGED` events per 100000 ticks                                                                                                                                                                                                                                                                                                                                                             |
| `eval.strain_family_focus`     | Kin is not a stranger                  | Of the infections passed on by contact (each emergence's own infection is left out), the share whose distance field is below 0.5 (the host is in the strain founder's family). `null` with reason `no-infections`                                                                                                                                                                                    |
| `eval.disease_frequency_slope` | One niche allowed to win the whole map | At each 1000-tick checkpoint, each family that `scene-families.js` tracks (both basins pooled) gives one point: x = its share of the living, y = infections of its members in the next 1000 ticks per member. The metric is the least-squares slope of y on x over all points of the run. Positive means common families are infected more per head. `null` with reason `few-points` under 10 points |

`eval.lineage_dominance` and `eval.basin_family_effective` are the existing detectors of the outcome; the balance round (world-balance.md T94 to T96) cites them.

## Decisions

| Decision                                                                                                | Why                                                                                                                                            | Who                         |
| ------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------- |
| The strain targets a genotype sampled from one random host; nothing reads which family is commonest     | A rule that picks the top family would be a global fact no blob senses; contact and relatedness make the cull frequency-dependent on their own | Planner, from principles.md |
| Immunity lasts for the strain's life                                                                    | Simpler than timed immunity, and a strain that is gone frees its bit                                                                           | Planner                     |
| No new sensor for a neighbour's infection in this doc                                                   | principles.md refuses sensors as a substitute for a scene; avoidance of the sick is added only if a later detector shows it impossible         | Planner, from principles.md |
| Off is `diseaseSeedRate` 0, not a boolean                                                               | No flag to delete later; the off arm stays a valid value                                                                                       | Planner                     |
| The contagion ships on by default at `diseaseSeedRate` 0.001, and its screen moves to the balance round | The balance round tunes the world with the contagion in it                                                                                     | User, 2026-11-03            |
| Disease lands before the balance round's runs (world-balance.md T84 onwards)                            | Balancing a world that the contagion then changes would be repeated                                                                            | User, 2026-11-03            |

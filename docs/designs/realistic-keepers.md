**Depends on:** [natural-selection.md](natural-selection.md), [refuge.md](refuge.md)

The goal ([principles.md](../principles.md)) is a world that is interesting to watch. The user's rule (2026-11-06): **a realistic
mechanism that does no harm is kept, even when it does not yet move its scene metric**. This doc restores the mechanisms that earlier docs deleted for
lack of a gain, re-checks them on today's defaults, adopts each that does no harm and deletes each that does.

The scenes served: **Parent spends** and **Kin is not a stranger** (provisioning, juvenile dependency), **A real chase** and
**Condition changes the walk** (sated bite, post-kill rest, reward-gated learning), **Scavenge** (herbivore meat value) and
**Refuge** (cover, the refuge sense). Each switch names its own scene metric; none is required to move.

## Principle - no harm first, scene second

- **Harm is the verdict, a scene gain is not required.** Eight-seed results never judge harm: they show a direction and
  only order the work.
- **Nothing pays fitness for the behaviour.** A mechanism changes a cost, a permission or an input; selection finds the
  use ([principles.md](../principles.md), "Measure scenes, reward them almost never").
- **A mechanism is realistic or it is not a candidate.** The Decisions table lists what is excluded and why.

### The keep rule (user, 2026-11-06)

A switch is kept when, over 16 floor-on seeds against the defaults on matched seeds, all of these hold:

1. Hunters are alive at the last tick on 12 of 16 seeds or more (the user's keep rule, unchanged; if the defaults arm itself
   falls short, the check is recorded and reported, not relaxed).
2. No more seeds end with a mean population under 80 than the defaults.
3. `eval:compare` shows no guard `worse`: `eval.population_mean`, `eval.predators_at_end`, `eval.prey_types_at_end`,
   `eval.spec_effective`, `eval.hunter_kill_conversion_by_age.1k-2k`, `eval.prey_extinctions`.
4. The mechanism's own scene metric is read and recorded; it is not required to improve.

### Phase 2 - No-harm checks

**Targets:** eval.population_mean, eval.predators_at_end, eval.prey_types_at_end, eval.spec_effective, eval.hunter_kill_conversion_by_age.1k-2k, eval.prey_extinctions

Every arm runs on the defaults as they stand after Phase 1: `npm run eval -- --seeds 16 --ticks 200000 --policy live --config
<arm.json> --out evals/results/<id>-<arm>.json`, floor on, seeds 1 to 16 of `../../evals/seeds.json`, against a defaults report
of the same seeds and ticks. Each run states its prediction in `evals/experiments.json` first. The verdict is the keep rule
read with `npm run eval:compare -- <defaults> <arm>`; a mechanism that fails any clause is deleted and one that passes is
adopted.

Seeds 17 to 32 (`--seed-offset 16`) are harsher (E130). They join the combined check only, so no per-mechanism verdict
rests on a seed range the keep rule was not calibrated on.

The combined run puts every kept mechanism on together, floor on, as two 16-seed reports (`--seed-offset 0` and `16`),
against the defaults on the same 32 seeds. The keep rule applies to each report. When the combination harms, the mechanism
added last in the Phase 1 order (satedBite, predatorRestTicks, provisioning, juvenile dependency, herbivore meat value,
rewardedHebb, coverConceals, coverFoodFree, refugeSense) is backed out and the run repeated until the rule holds.

### Phase 4 - Freeze and the reward-gating screen (proposed, 2026-11-07)

**Targets:** eval.hunter_conversion_gain, eval.skill_trend, eval.hunter_first_kill_km_median, eval.hunter_kills_per_life_p50, eval.hunter_zero_kill_share

The record of "From outcome to task" for the review of 2026-11-07. **Observation.** The keep rule judged every mechanism on harm, and the bundle is on: a world where hunters persist (13 of 16 seeds alive at the last tick in E140) with `eval.skill_heritability` 0.41 and `eval.skill_trend` -0.032, 3 of 16 seeds positive. Persistence is not practice ([hunter-learning.md](hunter-learning.md), "Principle - survival is not competence"). The keep rule was written for survival, and the scenes it checks are survival scenes. Reward-gated Hebbian learning stayed on although E124 showed it does not teach a kill (`eval.hunter_conversion_gain` negative in every arm, the shuffled arm the best): it passed the no-harm rule (E137) and nothing else. `rewardedHebb` and its off path were deleted in wasm-kernels.md Phase 1, so the gating is always on; `rewardGain` 4, `rewardBase` 0.25 and `rewardDecay` 0.02 are the config keys (`rewardScale` in `js/sim/reward.js` returns `rewardBase + rewardGain x trace`).

**Freeze.** No new keeper is adopted on survival alone. The next keeper that claims a hunting mechanism must move `eval.skill_trend`, the first-kill age (`eval.hunter_first_kill_km_median`) or `bite-discrimination` and `eval.bite_wish_with_prey_in_jaws` ([brain-reflex-tests.md](brain-reflex-tests.md), [hunter-practice.md](hunter-practice.md) Phase 1c), or it is not adopted. The user's keep rule for harmless realistic features stays for non-hunting mechanisms.

**Detector check (step 0).** The gating's own scene metric is `eval.hunter_conversion_gain`, whose negative null (E124 no-plasticity -0.048) made it unreadable alone; the screen reads it as a difference to the plain arm, beside `eval.hunter_first_kill_km_median`, `eval.hunter_kills_per_life_p50` (a mean) and `eval.hunter_zero_kill_share`, and `eval.skill_trend` on the 32-seed read.

**Theory.** The reward trace scales `hebbianStep`, which changes only `fastOut` (hidden to output) and never skip weights; the prey reflex lives in skip cells, so the gating cannot teach the reflex and may do nothing for hunting. Nature: dopamine-gated plasticity credits the act that paid, which helps only when the plastic path is the one that carries the skill. If plain Hebbian (the same rule, ungated) does as well on the competence detectors, the gating is cost and code with no scene.

| Theory or change                                                                                       | Serves                                            | Principle check                                                                                                                                                                          | Verdict         |
| ------------------------------------------------------------------------------------------------------ | ------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------- |
| (a) Screen plain Hebbian (`rewardBase` 1, `rewardGain` 0, so the scale is 1) against the gated default | Trait "same genome, different animal at each age" | A config arm: no code, no reward term in fitness, merit or archive rank; the gate modulates plasticity and pays nothing for a kill; judged on competence detectors                       | Task (T27, T28) |
| (b) Delete the gating if the screen shows it does nothing                                              | Simplicity; rule 9                                | A deletion of a realistic mechanism that did no harm, allowed under the freeze because it moves no competence detector; the Rust and JS paths go together (wasm-kernels.md, no fallback) | Task (T28)      |
| (c) Adopt a new hunting keeper on survival alone                                                       | none                                              | Refused by the freeze: survival is not competence                                                                                                                                        | Refused         |

**Prediction and detector (`E-BC-6`, written before the run; placeholder id).** On 16 floor-on seeds the plain arm and the gated default read the same on `eval.hunter_conversion_gain`, `eval.hunter_first_kill_km_median`, `eval.hunter_kills_per_life_p50` and `eval.hunter_zero_kill_share` (every paired interval spans 0), so the gating does nothing for hunting. Falsified when the gated default beats the plain arm on `eval.hunter_conversion_gain` or the first-kill median with the interval excluding 0 and a change of at least 5% of the plain mean: the gating is then kept and its scene named. A deletion also needs the 32-seed paired read of the keep rule (hunters alive on 12 of 16, no more seeds under 80, no guard `worse`).

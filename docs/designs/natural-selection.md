# Natural selection

**Status:** Proposed - Phase 1 first: the scene and selection detectors, then the flagged changes (floor guard, poor entrants, proven lines, chance-free breeding, mate rank, actor-only credit, the input layout and the season input); one switch-on in Phase 2.
**Validated:** d8a8561 (2026-10-29)
**Priority:** 1 - the default world fails the principles (spinning, a scout monoculture, lucky lives that breed, dead genomes that return), and one flagged build with one switch-on avoids a re-pin per tuning round (user, 2026-10-29)
**Depends on:** [fitness-and-selection.md](fitness-and-selection.md) (Phases 1 to 3 built, T48h and T48i built)

Right now a lucky life can still breed and a dead failure can still come back. [principles.md](../principles.md)
(version 2) states the rules: death is final, a lucky life does not found a line, strength is who remains after the bad
season, incompetence kills before fertility ranks, and a payoff must return to the actor's offspring. This doc builds
the changes that enforce them, and the detectors that show whether the scenes appear.

Each change is a config key or policy option that defaults to off or to today's value, so the golden hashes and the
baselines do not move while Phase 1 lands. Phase 2 turns the chosen set on in one PR and re-pins once. Phase 3
attributes the effect of each change with leave-one-out arms.

Out of scope: new sensors, new brain layouts beyond `pooled-v2`, the brain experiments
([brain-capacity-and-memory.md](brain-capacity-and-memory.md) follows this doc), and any reward for a scene
(principles.md, "Measure scenes, reward them almost never").

### The proof rule

An agent is **proven** when its own `deliberateIntake` reaches `splitDeliberateMin` and its deliberate meal share
reaches `splitDeliberateShareMin` (the split gate, without the population bypass). It is evaluated each time a meal is
credited, so it can happen at any age. A genome is **established** when its bearer is proven and at least one child of
that bearer is proven too: the skill was repeated without anyone paying for it. Rule 2 applies to every birth:

- **Split and mate children both count.** For a mate birth, the child counts for both parents, so both lines may become
  established by it.
- **Archive (`archive`).** A death enters the archive only if the dead genome is established. A parent that dies before
  its child is proven is held in a pending table (its death-log row and genome, at most `maxAgents` entries) and
  archived when the child proves; the entry is dropped when the child dies unproven.
- **Split brake (`split`).** A parent with a child alive that is not yet proven (from a split or a mate birth) cannot
  split. Mating itself is not blocked.
- **`both`:** both rules. An arm that removes one half is not run: `no-proof` turns the whole rule off.

Per-slot arrays `proven` and `unprovenKids`, the parent genome ids and the pending table are derived state beside the
split-gate counters: zeroed by `freeAgent`, outside `worldHash`, no RNG, no allocation per tick.

## Detectors

Each is an observer metric with a test on a hand-built world, direction `watch` unless it says one, no sim state
change (the golden `worldHash` is unchanged) and no per-tick allocation.

## Phases

### Phase 1 - Build behind flags

**Targets:** none - every key defaults to the current behaviour; the new `eval.*` metrics are instruments (`watch`), and no existing metric moves

The detectors, the keys and the `socialCredit` option, each with its tests and its log events. Batches of 2 to 4
tasks per PR, one commit per task. The predator-survival screen (T5) is a screen and is not batched with code.

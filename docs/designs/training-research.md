# Training research

**Status:** Reference - a survey for [training-stages.md](training-stages.md): what the training tools are today, what their runs showed, how staged multi-agent training is done and judged elsewhere, and the gaps between the two.

Read against `origin/main` at f5ebac76 (2026-11-15). No run was made for this survey. The papers are cited from memory and are to be checked before a number from them is relied on.

## How staged training is done elsewhere

| Practice                        | Source                                                                                                           | Problem it solves                                                                                   | Here today                                                                                        |
| ------------------------------- | ---------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------- |
| Curriculum: easy tasks first    | Bengio et al. 2009 (ICML); Elman 1993                                                                            | A skill with a sparse payoff is never reached from random behaviour                                 | Present: `nursery` then `hunt`                                                                    |
| Mastery gates                   | Unity ML-Agents lessons with completion thresholds; teacher-student curricula (Matiisen et al. 2017)             | A fixed lesson length moves on before the lesson is learned, or wastes time after it                | Absent: a stage ends on a generation count                                                        |
| Automatic difficulty            | Automatic domain randomisation (OpenAI 2019, Rubik's cube); POET (Wang et al. 2019); PAIRED (Dennis et al. 2020) | A hand-set difficulty is too hard or too easy; the environment is widened only as the learner copes | Absent: prey density and arena size are hand-picked per arm                                       |
| Rehearsal and regression checks | Continual learning (Kirkpatrick et al. 2017; replay methods)                                                     | A later lesson overwrites an earlier one                                                            | Absent: nothing re-reads a passed stage's skill after the stage changes                           |
| Self-play                       | TD-Gammon (Tesauro 1995); AlphaGo Zero (Silver et al. 2017)                                                      | The opponent is always at the learner's level, so the lesson is always reachable                    | Present in effect: hunters and prey of one archive share each world                               |
| Past opponents (hall of fame)   | Rosin and Belew 1997; OpenAI Five (2019) played 20% of games against past selves                                 | Co-evolution cycles: a counter to today's opponent forgets how to beat yesterday's                  | Absent: founders come only from the current archive                                               |
| League with exploiters          | AlphaStar (Vinyals et al. 2019): main agents, main exploiters, league exploiters, prioritised opponent sampling  | A population that only meets itself keeps a shared blind spot                                       | Absent. The MAP-Elites archive gives variety of style, not opponents chosen to expose a weakness  |
| Autocurricula from competition  | Hide-and-seek (Baker et al. 2020); Capture the Flag (Jaderberg et al. 2019)                                      | Each side's progress is the other side's next lesson, with no hand-written stage                    | Possible in the `hunt` stage; never shown, because the hunters never reached the kill             |
| Predator and prey co-evolution  | Nolfi and Floreano 1998; Cliff and Miller 1995                                                                   | Shows arms races, and that apparent progress is often a cycle                                       | No instrument reads either                                                                        |
| Quality diversity               | MAP-Elites (Mouret and Clune 2015); novelty search (Lehman and Stanley 2011)                                     | A single best score deletes the second way of doing the job                                         | Present in the archive (`descriptorV7`: role skill by style); lost at export, one champion a spec |
| Scripted sparring partners      | AlphaStar and OpenAI Five both met built-in bots early                                                           | Bootstraps a skill before any learned opponent can teach it                                         | Used in drills only (`COMBAT_CONTROLLERS`); never in a training world (user, 2026-10-17)          |
| Population-based training       | Jaderberg et al. 2017                                                                                            | Tunes hyperparameters while training                                                                | Not needed: the genome carries its own mutation sigma                                             |
| Reward shaping                  | Ng et al. 1999                                                                                                   | Speeds a sparse task                                                                                | Refused by [principles.md](../principles.md): the curriculum changes the world, never the reward  |

## How "good" is judged elsewhere

| Check                       | Source                                                                                | What a pass shows                                                         | Here today                                                                                     |
| --------------------------- | ------------------------------------------------------------------------------------- | ------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------- |
| Baselines                   | Standard practice: random, scripted and previous-best agents on the same episodes     | The number is above chance and near a known skilled bar                   | Present: random brains and `referenceSubject('memoryless')`                                    |
| Intervals and replication   | Agarwal et al. 2021 (interquartile means, bootstrap intervals); Henderson et al. 2018 | A result is not one seed's luck                                           | Partly: 3 seed offsets is the rule since T22; drill tables print no interval                   |
| Held-out evaluation         | Procgen (Cobbe et al. 2020)                                                           | The skill is not memorised from the training seeds                        | Present: `evals/train-seeds.json` is disjoint from `evals/seeds.json`                          |
| Behaviour suites            | bsuite (Osband et al. 2020); the hide-and-seek transfer tests                         | Each named capability is tested alone, so a failure names what is missing | Present: drills and reflex cases; none for a pack, a crossing prey, a flank or kin in the jaws |
| Ratings                     | Elo, TrueSkill                                                                        | An ordering of agents from games                                          | Built, unused: the league has no admitted champion                                             |
| Cross-play matrix           | Master tournament (Nolfi and Floreano 1998); CIAO plots (Cliff and Miller 1995)       | Today's agents beat every past opponent: progress and not a cycle         | Absent                                                                                         |
| Exploitability              | PSRO (Lanctot et al. 2017); AlphaStar exploiters                                      | No cheap counter-strategy exists                                          | Absent; the selection rule "Cheaters are the test" asks for it                                 |
| Diversity                   | QD-score and coverage (Pugh et al. 2016)                                              | More than one way of living is kept                                       | Present for the archive (`coverage`, `qdScore`); `eval.style_separation` is unverified         |
| Specification gaming review | Krakovna et al. 2020; Goodhart's law                                                  | The score was earned by the intended behaviour                            | Present as practice: "check the detector first"; the T20 lost-trial trace                      |
| Human evaluation            | Standard for behaviour meant to be watched                                            | A person agrees it looks right                                            | Named (the clip, the user's watch); never done for a trained champion                          |

For this project "good" has a stricter meaning than a high score. From [principles.md](../principles.md): a viewer can narrate a life; the children repeat the skill without a bonus (rule 9); a courser and an ambusher both survive export; the scene shows on a verified detector in the target world; and no stage paid for an act.

Each finding is read from the definition, not from a run; the fix task re-checks it on a hand-built world first. Metrics owned by another plan are listed with that plan and get no task here.

## Gaps

| #   | Gap                                                                                                                               | Closed by ([training-stages.md](training-stages.md)) |
| --- | --------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------- |
| G1  | A stage ends on a count, so the `hunt` stage ended with no kill learned and the next stage would have been built on nothing       | Phase 2: gates                                       |
| G2  | Nothing re-reads a passed lesson, so forgetting is invisible                                                                      | Phase 2: retention and review                        |
| G3  | Drill edges carry no interval, and a gate on 32 trials would pass on luck                                                         | Phase 1: Wilson bounds; 3 offsets                    |
| G4  | Runs are not kept: archives in `/tmp`, no manifest                                                                                | Phase 2: run directory and manifest                  |
| G5  | Hunter and prey progress against each other is unread; a cycle looks like progress                                                | Phase 3: cross-play                                  |
| G6  | Opponents come only from the current archive                                                                                      | Phase 3: opponent pool                               |
| G7  | No drill for the scenes the user names first: a pack, a prey that breaks line, a flank, kin in the jaws                           | Phase 4: scene drills                                |
| G8  | Export keeps one champion a specialisation, which deletes "Same spec, different custom"                                           | Phase 4: export by style                             |
| G9  | No single answer to "is this champion set good": the checks are spread over five commands and none reads inheritance              | Phase 5: the exam                                    |
| G10 | The ladder stops at `hunt`: nothing stages evading a hunter that hunts, an arms race, a pack or a habitat before the target world | Phase 6: the stage worlds                            |
| G11 | A rules change voids every champion, and retraining is a hand-run list of commands                                                | Phase 7: `npm run train:season`                      |
| G12 | Chase, pack, style and zero-kill metrics misread what a training run needs (Metric audit, A1 to A14)                              | Phase 1: detectors                                   |

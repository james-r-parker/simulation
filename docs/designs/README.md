## Build queue (21)

Unbuilt docs in priority order - 1 is built next. Set in each doc's `**Priority:**` line; the evolution loop proposes re-ranks.

1. [Natural selection](natural-selection.md) - the default world fails the principles (spinning, a scout monoculture, lucky lives that breed, dead genomes that return), and one big-bang build with every change on by default avoids flags, dual paths and a re-pin per tuning round (user, 2026-10-29)
2. [Realistic keepers](realistic-keepers.md) - the user's keep rule (2026-11-06) turns eight deleted or never-confirmed mechanisms into candidates the balance round can adopt now; it queues behind natural-selection.md (Priority 1), whose Phase 4 balancing owns the defaults, and ahead of refuge.md Phase 3 conclusion, whose T27 `refugeSense` reports T19 reads
3. [Refuge](refuge.md) - the Refuge scene is absent on the default world (`eval.refuge_use_under_threat` -0.003, E126 and E129), and cover is the classic stabiliser of the boom-and-dip the floor-off worlds show; it queues behind natural-selection.md (Priority 1), whose Phase 4 balancing is the parent body of work
4. [Training](training.md) - the drills and the trainer are tools that do not depend on the balance numbers, and the balance round needs trained champions to test whether unskilled founders cause the floor restarts (world-balance.md H10); champions reach the live world only after the world gate (user, 2026-10-16)
5. [Fitness and selection](fitness-and-selection.md) - after natural-selection.md (Priority 1), which closes this plan's Phase 4 when its T19 moves the status lines; the worlds sit in a scout monoculture where behaviour stops improving, and every later tuning night, the trainer and the champions measure a fitness this doc replaces
6. [Brain capacity and memory](brain-capacity-and-memory.md) - measurement before redesign: a brain experiment judged by `fitnessV1` measures the wrong thing, so it queues after natural-selection.md (Priority 1), which closes fitness-and-selection.md Phase 4 (user, 2026-10-29)
7. [World balance and biology](world-balance.md) - the post-feature balance round follows flora and megafauna; the current rank is unchanged
8. [Quality gates and test tiers](quality-gates-and-test-tiers.md) - Phase 3 (PR perf job, CPU lock in check.sh, busy-aware bench-check) protects every other lane while several agents share the machine (manager, 2026-10-17)
9. [Worker and renderer](worker-and-renderer.md) - comes before the trainer so world tuning can be judged by watching it, not only by scorecards (user, 2026-10-16)
10. [Improvement loop](improvement-loop.md) - automates measuring and proposing once the evolution rework and the renderer give it something worth tuning
11. [v6 tidy-up and docs](v6-tidy-up-and-docs.md) - the last stage of v6: nothing legacy is left and every doc describes the app as built
12. [Deployment and community](deployment-and-community.md) - the last stage: put v6 online, then open it to the community (user, 2026-10-16)
13. [Mobile view](mobile-view.md) - the app's audience is the TV and the desktop; a phone is a second screen, so this queues after the v6 and deployment docs
14. [Brain inspection](brain-inspection.md) - last in the queue (user, 2026-11-04): a diagnostic for champions that fail a drill, useful only once the drills and the trainer exist
20. [Habitat cover](habitat-cover.md) - it changes the map and re-pins the goldens, so it queues behind every unbuilt doc
21. [Alarm calls](alarm-calls.md) - the Call, or don't scene is absent (alarm rate 0, precision null on every diagnosis seed); it follows the refuge and keepers work because a call needs prey near kin and a hunter to bite, which cover and juvenile dependency change
22. [Seasonal movement](seasonal-movement.md) - the Season changes the map scene reads flat (`eval.winter_basin_density` and `eval.winter_pop_ratio` about 1.0), but nothing in the keep rule waits on it; it queues behind the balance and refuge work
23. [Hunter practice](hunter-practice.md) - the within-lifetime gain is negative in every E124 arm and the cause is a weak channel plus a biased detector, not a missing feature
24. [WASM kernels](wasm-kernels.md) - a speed lever that changes no behaviour (the behaviour-changing levers are ruled out), so it queues behind the world-balance work and ahead of nothing that depends on it
25. [Brain reflex tests](brain-reflex-tests.md) - a tool and a study that change no sim behaviour; it builds on the trainer and drills (training.md) and gets cheaper once the Rust brain kernel is adopted (wasm-kernels.md), so it queues behind both
26. [Renderer event effects](renderer-event-effects.md) - a viewer cannot yet tell most features are firing (user, 2026-11-07); it changes no sim behaviour, so it queues behind the balance and scene work

## Build queue (7)

Unbuilt docs in priority order - 1 is built next. Set in each doc's `**Priority:**` line; the evolution loop proposes re-ranks.

1. [Development workflow and gate](dev-workflow-and-gate.md) - every later doc measures against the legacy baseline this phase records
2. [Quality gates and test tiers](quality-gates-and-test-tiers.md) - the static gates and the coverage ratchet must exist before the first `js/sim` module is written
3. [Headless sim core](headless-sim-core.md) - every later doc (evals, evolution, worker) runs on this core
4. [Evolution evals](evolution-evals.md) - the evolution rework is judged against the baseline this doc records
5. [Evolution rework](evolution-rework.md) - better evolution is what makes a run worth watching, and it needs the evals to prove it
6. [Worker and renderer](worker-and-renderer.md) - the browser is where the simulation is watched, and it needs the core and the live policy first
7. [Improvement loop](improvement-loop.md) - automates measuring and proposing once the evolution rework and the renderer give it something worth tuning

### 2026-11-22 - Vitest `--no-isolate` breaks the fast tier, and a function-prefix env var leaks to children

The fast tier (1053 files, 10029 tests) takes 28 to 36 s with isolation and 28 to 30 s without it on a loaded machine, so the gain is small, and `--no-isolate` fails 14 to 17 tests in 6 files from run to run: `test/app/frame-alloc.test.js`, `test/evo/metric-source-world-watch.test.js`, `test/evo/trainer-failure.test.js`, `test/experiment.test.js`, `test/sim/effects-stored.test.js`, `test/sim/step-phases.test.js` (and `drill-sources`, `observer-phases` on another order): spies and module state leak between files. Isolation stays on. In bash, `VAR=x func` exports `VAR` to every child the function starts, so a lock mode set that way reached the tests the function ran; `with_cpu_lock_shared` in `scripts/lib/cpu-lock.sh` sets a plain variable instead.

### 2026-11-25 - A Vitest reporter sees each test's own timeout; the JSON report does not

The JSON reporter's assertion results carry a test's duration but not its limit, so a test given an explicit timeout (a third argument, or `scaleTimeout(...)`) cannot be compared with that limit from the report. A custom reporter can: `onTestRunEnd(modules)` reaches every `TestCase`, and its `options.timeout` is the limit the test ran under. `scripts/lib/limit-reporter.mjs` uses it for the over-half-limit warning in `npm run test:report` (agent-workflow.md T46). Splitting `test/evo/gate-validity.slow.test.js` by drill group took one 122 s file to four of 24 to 30 s: `gateValidity` reads only `drill.*` conditions, so a ladder filtered to a group's drills keeps every condition it checks.

### 2026-11-21 - The per-slot state contract found one array outside worldHash (registries Phase 1)

Declaring for each array of `agentSpecs` whether `hashWorld` covers it, and testing it by changing one element (`test/sim/world-state.contract.test.js`), confirmed every declared excuse (the stamps `recoilStamp`, `jawsStamp` and `pollenRefusalTick`, the rewritten `inputs`, `pooled` and `outputs`, the derived `childShare` and `leakRate`, `alarmSeen`) and found one gap: `restTimer`, the hunter's rest after a kill (`predatorRestTicks`, 60 by default), is in no hash list, though it holds thrust at 0 in `physics.js`. Its effect reaches the hashed `vx` and `vy` in the same tick, so no golden can miss a divergence in it for long, but hashing it would move every golden, so it stays in `UNHASHED_ROWS` with that reason until a PR that re-pins takes it.

Two layering rules the move ran into: `js/library` may import nothing from `js/sim/` (the `library-standalone` rule), so its `SPEC_NAMES` stays a copy that a test keeps equal; and `js/app` may not import `js/sim/events.js` (the `app-boundary` rule), so the cause colours reach the charts in the worker's `layout.causeColours`.

## High

- [ ] README maximum age is wrong
      Doc: README.md - "What we have now" (Time paragraph)
      Code: js/sim/config-defaults.js - `maxAgeTicks`
      Evidence: the Time paragraph says a blob lives at most `maxAgeTicks` (36,000 ticks). The default is 72,000. The same README's "What kills a blob" table says 72,000 (two seasons), so the README contradicts itself.
      Edit: change "36,000 ticks, 10 minutes at x1" to "72,000 ticks, 20 minutes at x1".

- [ ] README food cap is wrong
      Doc: README.md - "Food"
      Code: js/sim/config-defaults.js - `maxFood`
      Evidence: README says "At most `maxFood` 1,600 items". The default is 3,600.
      Edit: "At most `maxFood` 3,600 items, `initialFood` 300 at the start."

- [ ] README carcass share is wrong
      Doc: README.md - "Food", Carcasses bullet
      Code: js/sim/config-defaults.js - `carcassShare`; js/sim/carcass.js
      Evidence: README says a carcass is worth "half the energy it took in". The default `carcassShare` is 0.8.
      Edit: replace "half" with "`carcassShare` (0.8 by default) of".

- [ ] README leak-gene start contradicts itself and the code
      Doc: README.md - "How genomes encode and mutate", Random start bullet (and the Memory bullet in "The brain")
      Code: js/evo/mutation.js - `randomWeights`; js/sim/traits.js - `leakRateOf`; js/sim/config-defaults.js - `leakGeneStart`
      Evidence: the Random start bullet says leak genes start at 3, "keeping about 95% of its old value". The Memory bullet says they start at 0 (about a = 0.5). The code uses `leakGeneStart` = 0, and `leakRateOf(0)` gives a = 0.51. A gene of 3 gives a = 0.95, which keeps only about 5% of the old value, so the phrase is wrong in both places.
      Edit: "leak genes `leakGeneStart` (0), so a unit starts with a about 0.5 and keeps about half its old value each tick."

- [ ] README brain size is stated four different ways
      Doc: README.md - "The brain" (diagram, Size bullet, Memory bullet, Inputs heading), "How genomes encode and mutate", "Where it is heading"
      Code: js/sim/brain-layout.js - `brainLayout`
      Evidence: the Size bullet says 83 inputs and 4,578 floats per row. The "How genomes encode" section says a 7,183-float row. The Inheritance bullet says about 67 of 4,494 genes. "Where it is heading" says an 81-input pooled brain. `brainLayout(createConfig({}))` returns `inputCount` 92, `rawInputCount` 196 and `weightCount` 4,926 at the defaults. None of the four README figures matches.
      Edit: remove the hand-copied numbers and point at `brainLayout` in js/sim/brain-layout.js for the counts, or regenerate the numbers from `brainLayout` in one place and reuse them. Also reconcile the memory input indices: the diagram and Memory bullet say inputs 31 and 32, the outputs table says "input 33" and "input 34", and the Sex and memory row says 30 to 32. Check `writeMemoryInputs` in js/sim/body-inputs.js for the real indices before fixing.

- [ ] README describes the natural-selection build as unfinished, but its doc says it is merged
      Doc: README.md - "Where it is heading" (first paragraph and item 1 of the numbered list)
      Code: docs/designs/natural-selection.md - Status line ("the big bang is merged (PR #217)")
      Evidence: README says "What is left before the PR is the survival screen ... and the Chromium and bench re-records", and item 1 says "in progress ... The survival screen, the re-records and the PR remain." The status line of the doc says the big bang is merged and Phase 4 chunks are merged. The README and the doc disagree on what remains.
      Edit: replace both passages with the remaining work exactly as the Status line of natural-selection.md states it, or link to that line rather than restating it.
